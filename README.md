# Hiya Audio Intelligence Examples
Repository with code examples for using the Hiya Audio Intelligence Service.

# Example List
The following examples are available:
- Batch Testing: Python script for easily making authenticity verifications for all audios in a folder.
- Monthly Usage: Python script for easily checking the minutes of audio verified by an organization in the current month.
- Streaming Verification: Node.js script for real-time streaming audio authenticity verification over WebSocket, supporting both local (self-hosted) and upstream (Hiya API) targets.
